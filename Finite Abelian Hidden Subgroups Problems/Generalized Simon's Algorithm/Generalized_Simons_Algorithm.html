Generalized Simon's Algorithm¶

Simon's algorithm finds a hidden binary period. Its generalized form finds a whole subspace of periods. This notebook derives the sampling rule, implements the quantum circuit in Qiskit, and recovers a basis of the hidden subspace using classical binary linear algebra.

1. The problem¶

Let G=F2nG=\mathbb{F}_2^nG=F2n​, with bitwise XOR as addition. We are given oracle access to a function f:F2n→F2mf:\mathbb{F}_2^n\to\mathbb{F}_2^mf:F2n​→F2m​ and the promise that some subspace K≤F2nK\leq\mathbb{F}_2^nK≤F2n​ satisfies

f(x)=f(x′)⟺x⊕x′∈K.f(x)=f(x')\quad\Longleftrightarrow\quad x\oplus x'\in K.f(x)=f(x′)⟺x⊕x′∈K.

Thus fff is constant on each coset x+Kx+Kx+K and takes different values on different cosets. The function need not be linear. If dim⁡K=k\dim K=kdimK=k, each output has 2k2^k2k preimages and there are 2n−k2^{n-k}2n−k distinct outputs. Consequently, the output register must have room for them, so m≥n−km\geq n-km≥n−k.

The task is to return a basis s1,…,sks_1,\ldots,s_ks1​,…,sk​ such that

K={a1s1⊕⋯⊕aksk:a1,…,ak∈F2}.K=\left\{a_1s_1\oplus\cdots\oplus a_ks_k: a_1,\ldots,a_k\in\mathbb{F}_2\right\}.K={a1​s1​⊕⋯⊕ak​sk​:a1​,…,ak​∈F2​}.

A basis describes every hidden period without listing all 2k2^k2k elements. Different correct bases can describe the same subspace.

Hidden dimension Meaning
k=0k=0k=0 K={0}K=\{0\}K={0} and fff is one-to-one
k=1k=1k=1 K={0,s}K=\{0,s\}K={0,s}, the nonzero-period Simon problem
1<k<n1<k<n1<k<n Several independent hidden periods
k=nk=nk=n K=F2nK=\mathbb{F}_2^nK=F2n​ and fff is constant

This is the binary-subspace formulation of generalized Simon's problem. We will not require kkk as an input. The classical section explains how ordinary evaluations of fff certify that enough samples have been collected.

2. Quantum section¶

From an oracle query to a coset state¶

Use the reversible XOR oracle

Uf∣x⟩∣z⟩=∣x⟩∣z⊕f(x)⟩.U_f\lvert x\rangle\lvert z\rangle =\lvert x\rangle\lvert z\oplus f(x)\rangle.Uf​∣x⟩∣z⟩=∣x⟩∣z⊕f(x)⟩.

Starting with two zero registers, apply a Hadamard gate to every input qubit and then query the oracle:

∣0n⟩∣0m⟩⟼12n∑x∈F2n∣x⟩∣0m⟩⟼12n∑x∈F2n∣x⟩∣f(x)⟩.\lvert 0^n\rangle\lvert 0^m\rangle \longmapsto \frac{1}{\sqrt{2^n}}\sum_{x\in\mathbb{F}_2^n} \lvert x\rangle\lvert 0^m\rangle \longmapsto \frac{1}{\sqrt{2^n}}\sum_{x\in\mathbb{F}_2^n} \lvert x\rangle\lvert f(x)\rangle.∣0n⟩∣0m⟩⟼2n​1​x∈F2n​∑​∣x⟩∣0m⟩⟼2n​1​x∈F2n​∑​∣x⟩∣f(x)⟩.

To analyze the input register, imagine measuring the output and obtaining f(x0)f(x_0)f(x0​). The promise says that exactly the inputs in x0+Kx_0+Kx0​+K remain. The normalized input state is therefore

∣x0+K⟩=1∣K∣∑h∈K∣x0⊕h⟩.\lvert x_0+K\rangle =\frac{1}{\sqrt{|K|}}\sum_{h\in K}\lvert x_0\oplus h\rangle.∣x0​+K⟩=∣K∣​1​h∈K∑​∣x0​⊕h⟩.

The implemented circuit does not measure the output register. Ignoring it gives the same input measurement statistics as measuring it and discarding the result. This avoids a mid-circuit measurement.

Why the samples are orthogonal to every hidden period¶

Define the binary inner product by

x⋅y=(∑j=0n−1xjyj) mod 2.x\cdot y=\left(\sum_{j=0}^{n-1}x_jy_j\right)\bmod 2.x⋅y=(j=0∑n−1​xj​yj​)mod2.

The Hadamard transform acts as

H⊗n∣x⟩=12n∑y∈F2n(−1)x⋅y∣y⟩.H^{\otimes n}\lvert x\rangle =\frac{1}{\sqrt{2^n}}\sum_{y\in\mathbb{F}_2^n} (-1)^{x\cdot y}\lvert y\rangle.H⊗n∣x⟩=2n​1​y∈F2n​∑​(−1)x⋅y∣y⟩.

Applying it to the coset state gives

H⊗n∣x0+K⟩=1∣K∣ 2n∑y∈F2n(−1)x0⋅y(∑h∈K(−1)h⋅y)∣y⟩.H^{\otimes n}\lvert x_0+K\rangle =\frac{1}{\sqrt{|K|\,2^n}} \sum_{y\in\mathbb{F}_2^n} (-1)^{x_0\cdot y} \left(\sum_{h\in K}(-1)^{h\cdot y}\right)\lvert y\rangle.H⊗n∣x0​+K⟩=∣K∣2n​1​y∈F2n​∑​(−1)x0​⋅y(h∈K∑​(−1)h⋅y)∣y⟩.

Write

K⊥={y∈F2n:h⋅y=0 for every h∈K}.K^\perp=\{y\in\mathbb{F}_2^n:h\cdot y=0 \text{ for every }h\in K\}.K⊥={y∈F2n​:h⋅y=0 for every h∈K}.

For y∈K⊥y\in K^\perpy∈K⊥, every summand in the inner sum equals 111. Otherwise, choose h∗∈Kh_*\in Kh∗​∈K with h∗⋅y=1h_*\cdot y=1h∗​⋅y=1. Translation by h∗h_*h∗​ permutes KKK and reverses the sign of the sum:

∑h∈K(−1)h⋅y=∑h∈K(−1)(h⊕h∗)⋅y=−∑h∈K(−1)h⋅y.\sum_{h\in K}(-1)^{h\cdot y} =\sum_{h\in K}(-1)^{(h\oplus h_*)\cdot y} =-\sum_{h\in K}(-1)^{h\cdot y}.h∈K∑​(−1)h⋅y=h∈K∑​(−1)(h⊕h∗​)⋅y=−h∈K∑​(−1)h⋅y.

The sum is then zero. The binary inner product is nondegenerate, so dim⁡K⊥=n−k\dim K^\perp=n-kdimK⊥=n−k. Hence measuring the input produces

Pr⁡(Y=y)={2−(n−k),y∈K⊥,0,y∉K⊥.\Pr(Y=y)= \begin{cases} 2^{-(n-k)},&y\in K^\perp,\\ 0,&y\notin K^\perp. \end{cases}Pr(Y=y)={2−(n−k),0,​y∈K⊥,y∈/K⊥.​

The phase involving x0x_0x0​ disappears when amplitudes are squared, so this distribution is the same for every output coset. Each run supplies a uniformly random linear constraint on all hidden periods. It does not directly supply a hidden period.

A runnable oracle¶

For an explicit circuit, choose a binary matrix AAA with nnn columns and define fA(x)=Axf_A(x)=AxfA​(x)=Ax, with arithmetic modulo 222. Then

fA(x)=fA(x′)⟺A(x⊕x′)=0,f_A(x)=f_A(x') \quad\Longleftrightarrow\quad A(x\oplus x')=0,fA​(x)=fA​(x′)⟺A(x⊕x′)=0,

so this oracle hides K=ker⁡AK=\ker AK=kerA. Each 111 in AAA becomes a CNOT from an input qubit to an output qubit. Keeping the input register makes the oracle reversible even when AAA is not invertible.

The matrix is used only to build the demonstration oracle. The recovery routine receives the oracle and register sizes, without being given AAA or a basis of KKK. This linear family is easy to learn classically from basis-vector queries. It illustrates the algorithm's operations, rather than providing a classical hardness benchmark.

The implementation uses m≥1m\geq1m≥1. A constant function can be represented by one zero output bit.

def make_linear_oracle(rows, n):
    '''Construct |x>|z> -> |x>|z XOR A x> from binary row strings.'''
    if not isinstance(n, int) or n < 1:
        raise ValueError("n must be a positive integer.")
    rows = list(rows)
    if not rows:
        raise ValueError("Supply at least one output row.")
    if any(not isinstance(row, str) or len(row) != n
           or set(row) - {"0", "1"} for row in rows):
        raise ValueError("Every row must be an n-bit binary string.")

    m = len(rows)
    circuit = QuantumCircuit(n + m, name="U_f")
    for output_position, row in enumerate(rows):
        output_qubit = n + m - 1 - output_position
        for input_position, bit in enumerate(row):
            if bit == "1":
                circuit.cx(n - 1 - input_position, output_qubit)
    return circuit.to_gate(label="U_f")


def check_oracle_size(oracle, n, m):
    if not isinstance(n, int) or not isinstance(m, int) or min(n, m) < 1:
        raise ValueError("Register sizes must be positive integers.")
    if oracle.num_qubits != n + m:
        raise ValueError("The oracle must act on exactly n + m qubits.")

Quantum sampling implementation¶

Each shot prepares the zero state, applies the two Hadamard layers around one oracle query, and measures only the input register. The figure produced below shows this circuit.

The same StatevectorSampler is reused across batches with a NumPy random generator, so successive calls advance the random state. The simulator API returns the measurements of register y as bit strings.

In [4]:
def generalized_simon_circuit(oracle, n, m):
    check_oracle_size(oracle, n, m)
    x = QuantumRegister(n, "x")
    z = QuantumRegister(m, "z")
    y = ClassicalRegister(n, "y")
    circuit = QuantumCircuit(x, z, y)
    circuit.h(x)
    circuit.append(oracle, list(x) + list(z))
    circuit.h(x)
    circuit.measure(x, y)
    return circuit


def sample_orthogonal(oracle, n, m, shots, sampler):
    if not isinstance(shots, int) or shots < 1:
        raise ValueError("shots must be a positive integer.")
    circuit = generalized_simon_circuit(oracle, n, m)
    result = sampler.run([circuit], shots=shots).result()[0]
    return result.data.y.get_bitstrings()


def evaluate_oracle(oracle, n, m, bitstring, sampler):
    '''Evaluate f on one classical input using the same XOR oracle.'''
    check_oracle_size(oracle, n, m)
    if (not isinstance(bitstring, str) or len(bitstring) != n
            or set(bitstring) - {"0", "1"}):
        raise ValueError("The input must be an n-bit binary string.")
    x = QuantumRegister(n, "x")
    z = QuantumRegister(m, "z")
    value = ClassicalRegister(m, "value")
    circuit = QuantumCircuit(x, z, value)
    for position, bit in enumerate(bitstring):
        if bit == "1":
            circuit.x(x[n - 1 - position])
    circuit.append(oracle, list(x) + list(z))
    circuit.measure(z, value)
    result = sampler.run([circuit], shots=1).result()[0]
    return result.data.value.get_bitstrings()[0]

3. Classical section¶

Recover a basis by solving binary equations¶

Place the sampled strings into the rows of a matrix YYY. Every hidden period s∈Ks\in Ks∈K satisfies

Ys=0(mod2).Ys=0\pmod 2.Ys=0(mod2).

If WWW is the row span of YYY, then the candidate subspace is

L=ker⁡Y=W⊥.L=\ker Y=W^\perp.L=kerY=W⊥.

All samples belong to K⊥K^\perpK⊥, so W⊆K⊥W\subseteq K^\perpW⊆K⊥ and therefore K⊆LK\subseteq LK⊆L. When the rows span all of K⊥K^\perpK⊥, their rank is n−kn-kn−k. Then dim⁡L=k\dim L=kdimL=k and L=KL=KL=K. Too few independent samples give a larger candidate subspace.

Use Gaussian elimination over F2\mathbb{F}_2F2​. Row addition is XOR and a nonzero pivot already equals 111, so no division is required. For each free column, set its variable to 111 and the other free variables to 000. The reduced equations determine the pivot variables. These solutions form a basis of the nullspace.

Real-valued rank and nullspace routines solve a different linear-algebra problem. The implementation below uses exact binary arithmetic.

In [7]:
def nullspace_gf2(bitstrings, n):
    '''Return a nullspace basis, reduced row matrix, and pivot columns.'''
    if not isinstance(n, int) or n < 1:
        raise ValueError("n must be a positive integer.")
    bitstrings = list(bitstrings)
    if any(not isinstance(row, str) or len(row) != n
           or set(row) - {"0", "1"} for row in bitstrings):
        raise ValueError("Every row must be an n-bit binary string.")

    reduced = np.array(
        [[int(bit) for bit in row] for row in bitstrings], dtype=np.uint8
    ).reshape(len(bitstrings), n)
    pivots = []
    pivot_row = 0
    for column in range(n):
        candidates = np.flatnonzero(reduced[pivot_row:, column])
        if candidates.size == 0:
            continue
        selected = pivot_row + int(candidates[0])
        reduced[[pivot_row, selected]] = reduced[[selected, pivot_row]]
        for row in range(len(reduced)):
            if row != pivot_row and reduced[row, column]:
                reduced[row] ^= reduced[pivot_row]
        pivots.append(column)
        pivot_row += 1
        if pivot_row == len(reduced):
            break

    free_columns = [column for column in range(n) if column not in pivots]
    basis = np.zeros((len(free_columns), n), dtype=np.uint8)
    for index, free in enumerate(free_columns):
        basis[index, free] = 1
        for row, pivot in enumerate(pivots):
            basis[index, pivot] = reduced[row, free]
    return basis, reduced, pivots


def as_bitstrings(vectors):
    return ["".join(str(int(bit)) for bit in vector) for vector in vectors]

Certify completion without knowing the hidden dimension¶

A rank that stops increasing for a few shots does not prove that the samples are complete. Instead, the oracle promise gives an exact membership test:

v∈K⟺f(v)=f(0).v\in K\quad\Longleftrightarrow\quad f(v)=f(0).v∈K⟺f(v)=f(0).

Let v1,…,vℓv_1,\ldots,v_\ellv1​,…,vℓ​ be the computed basis of L=ker⁡YL=\ker YL=kerY. If every basis vector passes this test, all of their binary combinations belong to KKK, since KKK is a subspace. Thus L⊆KL\subseteq KL⊆K. Together with K⊆LK\subseteq LK⊆L, this proves L=KL=KL=K.

If any basis vector fails, gather more quantum samples. At most ℓ+1\ell+1ℓ+1 ordinary function evaluations are needed for one check, including f(0)f(0)f(0). An empty basis means L={0}L=\{0\}L={0}, so K={0}K=\{0\}K={0} without further queries.

If kkk is supplied as part of the promise, reaching rank n−kn-kn−k is an alternative stopping criterion. The implementation below uses the membership checks so that it also works when kkk is unknown.

The classical decision uses only function values. The helper evaluate_oracle realizes each ordinary evaluation through a computational-basis circuit, whose ideal output is deterministic.

In [9]:
def certify_hidden_subgroup(bitstrings, n, evaluate_f):
    '''Return (basis, rank) if certified, otherwise (None, rank).'''
    basis, _, pivots = nullspace_gf2(bitstrings, n)
    if len(basis) == 0:
        return [], len(pivots)
    zero_value = evaluate_f("0" * n)
    basis_strings = as_bitstrings(basis)
    for vector in basis_strings:
        if evaluate_f(vector) != zero_value:
            return None, len(pivots)
    return basis_strings, len(pivots)


def recover_generalized_simon(
    oracle, n, m, *, batch_size=12, max_batches=6, seed=2026
):
    '''Recover and certify a basis of K, or report the sample limit.'''
    check_oracle_size(oracle, n, m)
    if (not isinstance(batch_size, int) or batch_size < 1
            or not isinstance(max_batches, int) or max_batches < 1):
        raise ValueError("Batch sizes and limits must be positive integers.")

    sampler = StatevectorSampler(seed=np.random.default_rng(seed))
    function_queries = 0

    @lru_cache(maxsize=None)
    def evaluate_f(bitstring):
        nonlocal function_queries
        function_queries += 1
        return evaluate_oracle(oracle, n, m, bitstring, sampler)

    all_samples = []
    for batch in range(1, max_batches + 1):
        all_samples.extend(
            sample_orthogonal(oracle, n, m, batch_size, sampler)
        )
        basis, rank = certify_hidden_subgroup(all_samples, n, evaluate_f)
        if basis is not None:
            return {
                "basis": basis,
                "dimension": len(basis),
                "sample_rank": rank,
                "sample_count": len(all_samples),
                "verification_queries": function_queries,
                "batches": batch,
            }

    raise RuntimeError(
        f"Could not certify the subgroup within {len(all_samples)} samples. "
        "Increase max_batches for another bounded attempt."
    )

Insufficient data and limiting cases¶

With no constraints, the candidate nullspace is the whole input space. For the nonconstant demonstration oracle, certification rejects this candidate.

4. Success probability and computational cost¶

Put d=n−k=dim⁡K⊥d=n-k=\dim K^\perpd=n−k=dimK⊥. After ttt independent uniform samples, failure to span K⊥K^\perpK⊥ means that some nonzero linear functional on this ddd-dimensional space vanishes on every sample. There are 2d−12^d-12d−1 such functionals, and each vanishes on one uniform sample with probability 1/21/21/2. The union bound gives

Pr⁡(rank⁡Y<d)≤(2d−1)2−t<2d−t(d>0).\Pr(\operatorname{rank}Y<d)\leq(2^d-1)2^{-t}<2^{d-t} \qquad(d>0).Pr(rankY<d)≤(2d−1)2−t<2d−t(d>0).

Therefore t≥d+⌈log⁡2(1/δ)⌉t\geq d+\lceil\log_2(1/\delta)\rceilt≥d+⌈log2​(1/δ)⌉ suffices for failure probability below δ\deltaδ, where 0<δ<10<\delta<10<δ<1. Without knowing kkk, one may conservatively replace ddd by nnn. If d=0d=0d=0, every sample is zero and the candidate full space can be certified immediately.

Under the oracle promise and ideal sampling, a returned answer is correct. The bounded loop may instead report that it could not certify an answer. It never substitutes an uncertified candidate. This is a randomized sampling implementation with verification, not an implementation of the amplitude-amplification algorithms that guarantee a fixed query bound.

For one batch collection totaling ttt samples:

  • Quantum sampling uses ttt oracle calls, 2nt2nt2nt Hadamard gates, and ntntnt input measurements.
  • The displayed binary elimination and basis construction use O(tn2+n2)O(tn^2+n^2)O(tn2+n2) binary operations and O(tn+n2)O(tn+n^2)O(tn+n2) storage.
  • A certification checks at most nnn candidate generators, plus f(0)f(0)f(0). Comparing a pair of output strings costs O(m)O(m)O(m).

The supplied loop recomputes elimination after each batch. If it takes BBB batches and ttt total samples, its elimination work is at most O(Btn2+Bn2)O(Btn^2+Bn^2)O(Btn2+Bn2). Let qqq be the number of distinct ordinary evaluations actually made. Caching gives q≤Bn+1q\leq Bn+1q≤Bn+1 and adds O(q(n+m))O(q(n+m))O(q(n+m)) storage. The function-evaluation costs are separate from these binary-operation counts.

If a realization of UfU_fUf​ costs CfC_fCf​ elementary gates, sampling and verification together use

O ⁣((t+q)(Cf+n+m))O\!\left((t+q)(C_f+n+m)\right)O((t+q)(Cf​+n+m))

gates and measured bits, with register initialization included in this upper bound. The demonstration oracle has at most mnmnmn CNOT gates.

These are costs for a quantum implementation. The statevector simulator stores O(2n+m)O(2^{n+m})O(2n+m) complex amplitudes. Keep the demonstration registers small. The exact equations and certification argument also assume ideal measurements. Noisy samples can invalidate K⊆ker⁡YK\subseteq\ker YK⊆kerY, so this notebook is not a noise-tolerant recovery method.
